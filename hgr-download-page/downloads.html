What's new in v1.1.0

New

  • System tray icon with live status — green ring when running, orange when paused, grey when off. Right-click for Pause / Settings / Quit.
  • Windows Jump List — right-click Touchless in the taskbar to Pause / open Settings / Quit without bringing the window forward.
  • Autostart with Windows — new toggle in General settings.
  • Smarter Settings search — General and About tabs are now indexed.
  • Dynamic gestures (early preview) — record motion-based custom gestures with the new recorder + clip picker. Accuracy is still being tuned.
  • Polished Custom-gesture creator — title bar matches the main window indigo; new Static/Dynamic split control.

Fixes & polish

  • Camera no longer glitchy on first launch — fixed mostly-black / corrupt-pixel first frames in the tutorial, app start, and the custom-gesture recorder.
  • ~50% lower dictation latency without losing accuracy.
  • Cleaner dictation — beam search + VAD filtering + hallucination thresholds cut spurious words.
  • Smarter grammar correction — triggers when you stop typing, aborts on resume, does a final pass at the end.
  • Smooth live view during fullscreen games — new lite paint mode + process-priority boost stop the camera from stuttering.
  • Spotify reauth toast — gentle prompt when your token expires instead of silent failure.
  • Tutorial Spotify step now auto-completes when music actually plays.
  • Consistent spacing on settings panel scroll bars; single green scroll bar on Control Guide.
  • Connect Phone is reachable when no webcam or mic is detected (dropdowns stay enabled).

Known issues

  • Dynamic gesture accuracy is mediocre — over-firing and missed-fires both happen. Re-record after each update; saved templates aren't forward-compatible across tuning changes yet.

System requirements

  • Operating system: Windows 10 or Windows 11 (64-bit).
  • Webcam: any USB or built-in camera at 720p/30fps or higher. Faster cameras reduce motion blur on gestures.
  • Microphone: required for voice commands and dictation. A headset or external mic works best; laptop/webcam mics are fine.
  • GPU (recommended): NVIDIA (CUDA 12.x) or any Vulkan-capable AMD/Intel GPU for fast voice transcription and grammar correction. CPU-only mode works but is slower.
  • RAM: 8 GB minimum, 16 GB recommended (voice and grammar models load together).
  • Disk space: about 6 GB free after install (includes whisper models and optional Qwen 3B grammar model).
  • First run: Windows may prompt to allow camera and microphone access — accept both.

How to install

  • Click Download for Windows to download the installer.
  • Open Touchless_Installer.exe after the download finishes.
  • Follow the setup prompts to install Touchless.
  • Launch Touchless from the desktop shortcut or Start menu after installation.

## Touchless 1.1.7 — What's new

**Recording quality**
- New Quality Level tier picker (Low / Normal / High) with a "Show more" explainer
- New 30-second clip preset — pick 30 s, 1, 2, or 5 min

**Gestures**
- Left-hand TWO is now the instant-clip gesture (hold for 0.5 s)
- Left-hand FIST retired
- Drawing swipes now fire from the same "one" pose you draw with
- New drift dead-zone — the pen stays still when your hand does

**Camera & tracking**
- Adaptive short-shutter for cheap USB webcams — sharper frames, smoother hand tracking
- Tighter landmark smoother — ~20 % less skeleton jitter
- Camera settings scrollbar fixed

**Overhauled dialog chrome**
- All 18 popups now use the Touchless indigo title bar on both Win10 and Win11
- Sharp square X close button on every dialog

**Settings search**
- Width auto-sizes to results, extends further down
- Single-character queries only match labels — no more noise
- Clicking a result on the same page scrolls to top instead of doing nothing
- New entries for Quality Level, Clip Duration, Discord / Spotify setup, and more

**Polish**
- Clip processing bar visibly reaches 100 % before hiding
- Text pop-ups off now silences the clip flow too
- 14+ tooltips shortened
- Debug-log-location popup at exit removed
- Top-right diagnostic HUD on the home page removed
